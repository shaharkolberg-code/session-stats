# Session Stats

Keeps track of how your current play session is going on each level.

## What you get
- **A HUD while playing**: attempts this session, your best run from 0%, your longest run from any start position, and how long you've been playing the level.
- **A run history**: pause the game and tap the stats button on the right to see every run this session (start % → end %), newest first. Deaths, completions and restarts are all listed, and practice runs are marked.

## Good to know
- Stats last until you close the game. Each level keeps its own stats, so you can switch levels and come back.
- Practice runs appear in the history but never count toward your best run.
- Play time only counts while the game isn't paused.
- On platformer levels, only attempts and time are shown, since percentages don't apply.
- The HUD's corner and opacity can be changed in the mod settings, or you can turn it off completely.
